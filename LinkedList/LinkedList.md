# Linked List Data Structure 

linked List is an important data structure that let you efficiently insert and delete data compared to arrays. Like arrays it also used to implement data structures like stack, queue and deque .<br>
A linked list is a type of linear data structure individual items are not necessarily at contiguous locations. The individual items are called nodes and connected with each other using links.
<br>
A node contains two things first is data and second is a link that connects it with another node.<br>
The first node is called the head node and we can traverse the whole list using this head and next links.

heres the comparaison between the Linked List and arrays : 

### Linked List:

- Data Structure: Non-contiguous
- Memory Allocation: Typically allocated one by one to individual elements
- Insertion/Deletion: Efficient
- Access: Sequential

### Array:

- Data Structure: Contiguous
- Memory Allocation: Typically allocated to the whole array
- Insertion/Deletion: Inefficient
- Access: Random
